Quick start

Send a latitude and longitude and get back the city, place, nearest road and region at that point.

Request

curl "ORIGIN/lookup?lat=38.982&lon=-76.937"

Response

{
  "city": "College Park",
  "place_name": "McKeldin Library",
  "state": "Maryland",
  "state_code": "MD",
  "county": "Prince George's County",
  "country": "United States",
  "country_code": "US",
  "road": "Campus Drive",
  "road_type": "tertiary",
  "road_distance_m": 41.7,
  "lat": 38.982,
  "lon": -76.937
}

Many points at once

curl -X POST "ORIGIN/lookup/batch" \
  -H "Content-Type: application/json" \
  -d '{"points":[{"lat":38.982,"lon":-76.937},{"lat":38.9786,"lon":-76.4909}]}'

Endpoints

GET takes lat and lon as query parameters; POST takes them as a JSON body.

  • /cityGET · POST

    City or town containing the point

  • /placeGET · POST

    Name of the building, point of interest or area at the point

  • /buildingGET · POST

    The building at the point, with its address and outline. Optional radius in metres (default 25, max 250)

  • /roadGET

    Nearest named road, its type and distance

  • /lookupGET · POST

    City, place, road, state, county and country together

  • /cities/batchPOST

    City for up to 100 points

  • /lookup/batchPOST

    Full lookup for up to 100 points

  • /healthGET

    Database connection check
